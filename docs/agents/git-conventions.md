# Git Conventions

## Commits

- Keep each commit focused on one logical change.
- Write a short imperative English subject without a trailing period.
- Add a body only when the motivation or important context is not clear from the subject.
- Do not use Conventional Commits prefixes.

Examples:

- `Fix Tk 9 compatibility`
- `Add WebP option to output file type`
- `Update development environment setup`
